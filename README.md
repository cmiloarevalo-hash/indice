# Biblioteca Desktop

Repositorio del proyecto **Biblioteca Desktop**, una futura aplicación local de escritorio para navegar y buscar el catálogo de libros.

## Fronteras del proyecto

- Este repositorio contiene el código y la documentación del proyecto; permanece separado del corpus de libros.
- El corpus objetivo está en `D:\Camilo\1. Respaldo\libroesoterico.com`.
- Durante el desarrollo, el corpus se trata como **READ-ONLY** salvo autorización posterior explícita.
- No se debe copiar, mover, renombrar, eliminar ni modificar contenido del corpus desde este proyecto.

## Distribución prevista

A futuro se prevé distribuir la aplicación como una aplicación portable junto al corpus. Este Work Item **no autoriza instalar, publicar, desplegar ni generar una release**.

## Estado actual

Este commit establece únicamente el bootstrap mínimo del repositorio. Todavía no incluye código de aplicación, framework, base de datos, dependencias ni configuración de CI.
